# Reglas iniciales

1. Solo se pueden reservar días configurados como disponibles.
2. La reserva corresponde al día completo.
3. La hora de referencia es 08:00.
4. No se puede superar la capacidad del día.
5. Un mismo correo no puede tener dos reservas confirmadas para el mismo día.
6. Una reserva cancelada deja de ocupar plaza.
7. Nombre, correo y día son obligatorios.
8. La nota es opcional.
9. Las confirmaciones y cancelaciones se registran como notificaciones locales.
