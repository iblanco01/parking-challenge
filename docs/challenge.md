# Enunciado

Construir una aplicación web para reservar plazas de parking de la empresa.

Este enunciado fija solo lo común a cualquier versión del reto. Qué debe hacer exactamente la aplicación, para quién y con qué reglas lo define `docs/intent.md` y lo concreta `docs/spec.md`. Si algo de este fichero difiere de `docs/intent.md`, manda `docs/intent.md`.

## Requisitos comunes

- La aplicación es web y permite reservar plazas de parking.
- La información debe persistir en base de datos y sobrevivir a un reinicio.
- Debe ser usable desde escritorio y móvil.
- Los datos de prueba son siempre ficticios. No se usan datos reales de personas.
- Las notificaciones, si las hay, se registran en local. No se envía correo real.
- Debe arrancar con las instrucciones del `README.md`.

## Qué se valora

- Que las reglas de negocio estén bien resueltas y probadas.
- Que la persistencia sea real.
- Que la interfaz sea clara en móvil y en escritorio.
- Que lo construido esté documentado y los criterios de aceptación se cumplan con evidencia.
