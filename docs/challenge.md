# Enunciado

Construir una aplicación web para reservar plazas de parking de la empresa.

El usuario debe poder:

- Consultar los próximos días disponibles.
- Seleccionar un día.
- Ver las plazas restantes.
- Introducir nombre, correo y una nota opcional.
- Confirmar una reserva.
- Consultar sus reservas.
- Cancelar o reprogramar una reserva.

La información debe persistir en base de datos. La aplicación debe ser usable desde escritorio y móvil.

## Contexto funcional

La reserva corresponde al día completo. La hora mostrada inicialmente, 08:00, es orientativa. Algunos días no están habilitados y otros pueden estar completos.
